# RP2040-based dev board
<img width="405" height="390" alt="Screenshot 2026-09-07 120425" src="https://github.com/user-attachments/assets/8e7580a4-f88c-4240-a81e-ee18245609ad" />

An open-source dev board featuring the **Raspberry Pi RP2040** microcontroller, USB Type-C interface, 2MB SPI Flash, and an integrated 3.3V LDO regulator.
---

## 🛠️ Hardware Specifications

- **Microcontroller:** Raspberry Pi RP2040 
- **Flash Memory:** Winbond W25Q16JVUXIQ 16M-bit SPI Flash 
- **Power Management:** Onboard 3.3V / 250mA LDO Regulator
- **USB Interface:** USB Type-C Receptacle with 5.1kΩ CC pull-downs
- **Clock Source:** High-precision 12MHz SMD Crystal Unit 
- **User Inputs:** Tactile Push Button for Reset / Bootloader mode
- **Form Factor:** Breadboard-compatible dual 20-pin breakout headers
